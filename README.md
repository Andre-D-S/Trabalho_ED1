# Trabalho de estrutura de dados I

O trabalho consistia em criar um registrador de humor. A forma de estruturar esses registros deveria ser uma lista duplamente encadeada, cada registro teria um ID único, a data do registro, o humor daquele dia, o motivo para tal humor e a nota de 0 a 10 do dia em questão. A organização dos arquivos em .c e .h também eram uma obrigatoriedade. Por fim, como incremento, foi pedido que os registros fossem salvos em um arquivo .txt.
